# Contributing

Read the [LICENSE](LICENSE), [NOTICE](NOTICE) and [implementation guide](code/README.md) before proposing a change. This repository is non-commercial source-available, not open source. This guide does not expand the permissions in the license.

## Ordinary Issues

Report non-sensitive bugs, documentation errors or suggestions through this repository's GitHub Issues, where enabled, or email [rcnsessions@gmail.com](mailto:rcnsessions@gmail.com).

Include the repository name, commit identifier, environment, command, expected result and actual result. Use synthetic fixtures and sanitized logs. Never attach credentials, tokens, signing keys, real learner records or private configuration.

Report suspected vulnerabilities privately using [SECURITY.md](SECURITY.md), not a public issue or pull request.

## Permission Before Code Submissions

The license prohibits distribution of modified versions and derivative works without prior written permission. Contact [rcnsessions@gmail.com](mailto:rcnsessions@gmail.com) before publishing a modified fork, patch or pull request. Obtain written permission that covers the proposed submission and its distribution; do not assume public access grants that permission.

Explain the proposed change, affected files, intended use and any third-party material. The copyright holder must approve contribution and licensing terms before code is accepted. This guide grants no automatic license, copyright assignment or commercial-use right for contributions.

## Approved Changes

After receiving written permission, follow its conditions and the code guide. Keep changes focused, preserve copyright and license notices, and include deterministic tests for changed behavior. Record the actual checks run and any checks not run; do not claim deployment or production evidence from unexecuted tests.

Use only systems and disposable environments you own or are authorized to test. Do not include generated secrets, private data or dependency code whose license does not permit the proposed use. Do not alter third-party license notices.
